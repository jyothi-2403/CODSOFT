## 📁 Projects Included

### 1. 🧮 Calculator (`/calculator1`)
A responsive web-based calculator that performs basic arithmetic operations with an intuitive UI.
- **Technologies**: HTML5, CSS3, JavaScript
- **Features**: Clean display layout, interactive buttons, real-time calculation logic.

### 2. 💼 Portfolio Website (`/portofolio`)
A personal portfolio website highlighting skills, projects, and contact details.
- **Technologies**: HTML5, CSS3
- **Features**: Interactive sections, downloadable resume (`jyoresume.pdf`), and profile layout.

### 3. 📝 Quiz Maker (`/quiz maker`)
An interactive quiz maker web application allowing users to navigate, create, and manage quizzes.
- **Technologies**: HTML5, CSS3, JavaScript
- **Features**: User login (`login.html`), quiz creation (`create.html`), quiz listing (`list.html`), and task view (`task.html`).

## 🚀 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/jyothi-2403/CODSOFT.git
   ```
2. Navigate into any project folder:
   ```bash
   cd CODSOFT/calculator1   # or /portofolio or "/quiz maker"
   ```
3. Open `index.html` in your web browser.
